## Problem (smoke-test forensics)

Dashboard smoke on xmom (`strategy_versions` id=20) showed repeated `coin_book_too_thin`
rejections on the top-ranked symbol every ~5 min with zero fills. Root cause was config +
design limits, not a bug:

1. **No cascade on rejection** — `top_n=1` + no fallback stalled entire cycles.
2. **Single all-or-nothing bet** — `top_n=1` proxy vs intended N-name basket.
3. **Boot-relative cadence** — `setInterval` at engine boot drifted across restarts; id=20 had a
   5-min smoke override on `rebalance_interval_ms`.

---

## What shipped

### Decision 1 — Rank-cascade (orchestrator-owned)

- `crossSectionalMomentumCore` returns the **full** eligible universe as `ranked` (dense rank 1..M);
  no `top_n` slice in the pure core.
- Shared contract: `IPortfolioSelection.selected` → `ranked`.
- `MomentumOrchestratorService.rebalance` restructured:
  1. **Definite de-rank closes** — symbol absent from `ranked` entirely.
  2. **Cascade walk** — hold open positions; gate-open new legs in rank order until `top_n` fills;
     gate-rejected candidates cascade to the next rank (uncapped depth, bounded by universe size).
  3. **Residual de-rank closes** — symbols in `ranked` but not in post-walk `retained` set (fixes
     churn bug: held positions outside naive top-N slice are never close-then-reopen).

### Decision 2 — `top_n` default 1 → 3

- `momentumParamsSchema` default `top_n: 3`.
- Fits existing 3 idiosyncratic slots (A/B/C) when VWAP pool is empty.
- **Known limitation (paper-only):** momentum legs still label `IDIOSYNCRATIC` / `idiosyncrasyScore=1`
  — three correlated movers can occupy A/B/C without slot-C protection. Recorded as **tech-debt H8**
  (go-live blocker before non-paper promotion).

### Decision 3 — Fixed 01:07 UTC cron

- `RebalanceSchedulerService`: `CronJob('7 1 * * *', timeZone: 'UTC')` replaces boot-relative
  `setInterval`.
- `MOMENTUM_REBALANCE_PERIOD_MS = 86_400_000` in `strategyConsts.ts`; `rebalance_interval_ms`
  validated on registration (WARN if mismatch) — downstream-only for time-stop net sizing.
- Fast local iteration: emit `UNIVERSE_REBALANCE_DUE_EVENT` manually (event seam), not param override.
