## Key decisions & rationale

**D1a as shipping path (not D1b v3 promotion):**
- Original spec assumed operator `pnpm engine strategy promote …` could flip v3 to active in-place. That path throws: `PromotionService.promote` rejects non-`draft` candidates (v3 is shadow); `StrategyService` resolves active by env-var PK; `PromotionGateService` has no soak path.
- D1a (subtractive v2 fallback) ships immediately on negative expectancy signal (−141.76 USDT, 104 trades); D1b (v3 promotion) is queued for engine work on soak-promotion pathway.

**D2 geometric lever: 3.5× long-side ATR multiplier + cost-floor anchor (not global raise or SL tighten):**
- Architect chose 3.5× as moderate bump (vs higher 4–5× candidates). Cost-floor anchor prevents tier2 TP re-enablement.
- Left SHORT side byte-for-byte unchanged (already ≈1.0 RR, no fix needed); long-side conditional branch enforces scope.
- SL stays structural (M38 / ADR 0045 §D1 invariant: "SL never rebased").

**D2 residual gap explicitly accepted (0.78 RR vs 1.46 breakeven):**
- Post-D1a win-rate recomputed (50% breakeven ≈1.46 for trending book). Median tier1 long at 3.5× lifts to ~0.78 (vs 0.445 at 2.0×). Gap ~0.68 remains.
- Reason: further TP widening risks recreating time-stop bucket; tightening SL touches structural invariant; trade-off accepted as designed, deferred to D3 selectivity work.

**7-day evidence foundation (not 24h):**
- Original 24h n=14 flagged "0/14 never reached TP band" as a path-fact. 7-day window (104 trades, −141.76 USDT) shows 30 TP exits, 11 trades reached TP band — path-fact falsified.
- Route now stands on **negative expectancy** (−141.76 USDT, 28.8% win rate, net-negative every cell + 5/8 days), which is robust to sample size and regime shifts (window spans multiple market days).
- **N=14 single-regime exemption withdrawn**; zero-TP-reach clause withdrawn.

**No ADR amendments in M43 for D1a/D2/D5:**
- D1a is a subtractive branch in active v2 (no new contract, flow-stamping already in ADR 0003 §4).
- D2 is pure constant/geometry change; ADR 0045 touch needed **only if** rebase contract shape changes (architect decided: pure constant, no touch needed).
- D5 is shared fidelity fix (no per-version branch, no new contract).
- D1b/D3 ADR work (0019 amendment, new soak-promotion ADR, 0003 amendment) deferred to future milestones.
