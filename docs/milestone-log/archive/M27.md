# M27 — Decision data-capture completeness

**Problem:** After M24–M26 landed the fill and shadow paths, decisions flowed to the DB but without context: why was a fill missed? what trade geometry did the gate approve? what was the internal halt reason on a rejected day? The `decisions` table had no decision metadata and `book_snapshots` had no link to the triggering event. This made forensic analysis (investigating why a particular signal rejected) a manual multi-query puzzle, blocking refinement cycles.

**Solution (code-only — no migration, no DB write at rest; 2 additive nullable migrations, zero deletes):**

**Dispatch A — Shared contract:** New `MissedReasonEnum` exported from `packages/shared/src/enum/` with 2 members: `MISSING_TICK_DATA = 'missing_tick_data'`, `PRICE_NOT_TOUCHED = 'price_not_touched'`. Typed `ISimulatedFill.missedReason: MissedReasonEnum | null`. Kept `ISimulatedFillCore.missedReason: string | null` intentionally (internal adapter values 'timeout'/'no_tick_cached' stay internal; only public contract uses typed enum). Zod schema updated. Barrel export added.

**Dispatch B — Engine: decisions trade geometry + halt detail.** Migration `20260708000000-AddTradeGeometryToDecisions.ts`: 8 additive nullable columns on `DecisionEntity` — `gate_allowed` (bool), `trade_side` (varchar), `stop_loss`/`take_profit`/`qty`/`notional`/`leverage` (numeric as text to preserve precision), `halt_reason_detail` (varchar). Migration adds columns + `down()` reversal (safe, no data loss). `IRiskDecision` interface gained `readonly haltReasonDetail: string | null`. `RiskGateService.evaluate()` returns `haltReasonDetail` on all return paths: fresh stress gates return null, already-halted-day returns verbatim `halt_reason` from the row, all other outcomes return null. `StrategyService.stampGateVerdict` populates geometry by decision outcome: approval writes clampedExit (SL/TP) + approvedSizing (qty/notional/leverage) + `gate_allowed=true` + `trade_side` from intent; reject writes proposedExit (SL/TP) + null sizing + `gate_allowed=false` + null side; skip writes all geometry null. `buildGateContext(symbol)` returns `{ context, openPositionsCount }` from a single `findOpen()` query (eliminates second DB call). `stampGateVerdict` uses threaded count for `active_positions_count`. `marketSnapshotMapper` removed dead constant `ACTIVE_POSITIONS_COUNT_DRY_RUN`, imported `ACTIVE_POSITIONS_COUNT_DEFAULT = 0` from `strategyConsts.ts`.

**Dispatch C — Engine: book_snapshots event_id writer + Zod hard-fail.** Migration `20260708000001-AddEventIdToBookSnapshots.ts`: adds `event_id` varchar nullable, `mid_at_trigger` numeric(38,18) nullable, partial UNIQUE INDEX `WHERE event_id IS NOT NULL` (prevents key collision; null event_id allowed for any number of rows). `BookSnapshotEntity` updated with `eventId?` and `midAtTrigger?` (decimal transformer). New `MarketDataPersistenceListener.onVolatilityDetected` handler + `recordBookSnapshot` best-effort writer: persists book snapshot paired to the event_id that triggered the volatility. Writer swallows duplicate-key (debug log) and all other errors (warn log), never rethrows. `DecisionRepository.findByEventId` method removed (was dead). Zod validation guard: throws in TEST env (injects `AppConfigService`), warns in others (does not block). `SchemaValidationService.book_snapshots` required-columns list updated to include `event_id` and `mid_at_trigger`.

**Dispatch D — Shadow: missedReason enum.** `ShadowStrategyOrchestratorService.deriveMissedReason` now returns `MissedReasonEnum | null` using typed enum members (was inline string literals).

**Tests:** 64 new across 5 suites. `StrategyService.m27.spec.ts`: geometry population by outcome (approval/reject/skip), geometry nullity on skipped coin, halt_reason_detail thread. `marketSnapshotMapper.m27.spec.ts`: ACTIVE_POSITIONS_COUNT_DEFAULT import + usage. `MarketDataPersistenceListener.m27.spec.ts`: book-snapshot write, event-id pairing, best-effort error swallowing (duplicate-key log, all-errors warn). `DecisionRepository.m27.spec.ts`: Zod guard TEST-env throw, other-env warn, no hard-block. `ShadowStrategyOrchestratorService.m27.spec.ts`: missedReason enum. `BacktestOrchestrator.spec.ts`: updated mock literals to include `haltReasonDetail: null`.
